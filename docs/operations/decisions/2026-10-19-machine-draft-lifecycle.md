# 기계 초안 자동 생명주기

## 목적

운영자가 실제로 읽지 않는 기계 초안을 `사람 검토 대기`로 쌓아 두지 않는다. 품질 검사는 유지하되, 미발행 초안이 Persona의 다음 생성 기회를 영구 점유하지 않게 한다.

## 정본 정책

- 자동 READY 판정에 적격인 기계 초안은 `autoReadyPending`이다. 다음 자동 도장 회차가 처리하므로 잠시 WIP로 센다.
- 경고나 품질 예외가 있는 기계 초안은 `qualityQuarantine`이다. 자동 발행하지 않고 WIP로도 세지 않는다.
- 옛 품질 계약, 무효가 된 자동 도장, gate 차단 행은 보존하되 운영자가 일일이 구제하지 않는다.
- 발행 후 표본 감사와 확정 결함 차단은 그대로 유지한다. 사전 수동 승인 제거는 사후 감사를 제거한다는 뜻이 아니다.
- 큐 행은 삭제하거나 과거 판정을 덮어쓰지 않는다. 이 변경은 재고 분류와 생성 여력만 바로잡는다.

## 운영 결과

- 창업자와 운영자는 기계 초안별 `ready/edit/reject` 결정을 하지 않는다.
- 자동 적격 글은 기존 자동 READY 경로만 통과한다.
- 자동 부적격 글은 발행되지 않지만 새 원천과 새 초안을 만들 Persona 자리도 막지 않는다.
- 자동 재작성은 별도 생성 단계 개선으로 다룬다. 격리된 과거 초안을 다시 살리는 경로로 만들지 않는다.
