# D100 목표 정본 — 공개 커뮤니티 글 100/day

> 확정 2026-09-21 · 창업자
> 🔴 이 문서가 **목표에 관한 유일한 정본**이다. 다른 문서가 다르게 말하면 그 쪽이 낡았다.
> 🔴 숫자는 문서가 아니라 코드에 있다 — [`src/lib/d100-capacity.ts`](../../src/lib/d100-capacity.ts).
> 보고서는 `npm run d100:readiness` 가 그 코드에서 만든다.

## 1. 목표 (변경 불가)

> **지금의 커뮤니티형 원문 기반 글을 Persona 가 자연스럽게 작성하고,
> 하루 3 → 5 → 10 → 20 → 30 → 50 → 100편으로 확대 발행한다.
> SEO 는 별도 글 종류가 아니라, 이 커뮤니티 글들이 검색에 노출되어 유입을 만드는 결과다.**

- 단위는 **공개 발행**이다. Shadow·Queue 후보·내부 생성이 아니다.
- **North Star 는 주간 재방문 참여 실사용자**다. 공개 글 100/day 는 그것을 움직이는 **수단**이다.

## 2. 금지

- 별도 SEO 정보형 글 레인 생성
- 검색용 기사·가이드·매거진을 D100 목표에 섞기
- **Shadow 100/day 를 공개 100/day 의 대체 목표로 바꾸기**
- Persona 공개 100/day 목표를 과거 문서 결정으로 다시 뒤집기
- 발행량·Persona 활동을 North Star 에 포함하기

## 3. superseded — 과거 결정 (지우지 않는다)

역사 기록은 남긴다. 다만 **지금 정본과 동시에 참으로 읽히지 않게** 표시한다.

| 과거 표현 | 어디 | 지금 |
|---|---|---|
| `Shadow100 — Queue 후보 100/day (별도)` | MASTER-OPERATING-SYSTEM §6 규모 표 | 🔴 **superseded.** Shadow 는 공개 100/day 의 **선행 지표**이지 목표가 아니다 |
| `SEO100-200 — indexable 콘텐츠 100~200/day (별도 Lane · 설계 없음)` | 같은 표 | 🔴 **superseded.** 별도 레인을 만들지 않는다. SEO 는 커뮤니티 글의 **결과**다 |
| "공개 발행 100/day 가 목표가 아니다" 류의 옛 결정 | 초기 D100 논의 | 🔴 **superseded** (2026-09-21 창업자 재확정) |

## 4. 단계 (코드 정본에서 생성)

`npm run d100:readiness` 가 아래 표를 만든다. **이 문서에 숫자를 복사해 두지 않는다** —
복사하면 반드시 한쪽이 낡고, 낡은 쪽이 먼저 읽힌다.

단계는 `d3 · d5 · d10 · d20 · d30 · d50 · d100` 이고, 각 단계가 내는 값은
공개/day · 상세 수집/day · READY 순증가/day · 14일 재고 · 활성 Persona · 댓글/day ·
발행 슬롯 수 · 최소 관측 일수다.

🔴 **이번 PR 은 release stage 를 올리지 않는다.** 새 단계를 활성화하지도 않는다.

## 5. 82cook

🔴 **82cook 은 대체하거나 포기할 공급원이 아니다. D100 의 필수 수집원이다.**
복구 계약과 일정은 [`src/lib/collect-82cook-recovery.ts`](../../src/lib/collect-82cook-recovery.ts)
가 정본이고, 준비도 보고서가 그 값을 읽어 적는다.

과거 차단의 **기록된** 원인은 `NETWORK` 11회 연속이다 — `403`·`429` 는 없었다.
쿠키 없음 · 상세 직접 접근 · 회차 50건 연속은 **원인 후보**이지 확정 원인이 아니다.
D10 준비 canary 가 그것을 가를 첫 관측이다.
