## 완료 지표

**`OriginalPostApprovalQueue` 의 APPROVED 순증가/day 하나다.**

수집 요청 수 · 회차 수 · 신규 thin 수는 완료 지표가 아니다.
그것들은 "남의 서버를 얼마나 두드렸나" 이지 "쓸 수 있는 글이 얼마나 늘었나" 가 아니다.

## 🔴 아직 모르는 것

- **APPROVED 순증가/day** — 24시간 관측(2026-09-11 22:31 → 09-12 22:31 KST)이 끝나야 나온다.
  🔴 Queue 전체 생성 건수를 순증가라고 부르지 않는다.

  🔴 서로 다른 모집단(재처리 cohort 와 누적 detail)을 한 퍼널로 이어 전환율을 만들지 않는다.
