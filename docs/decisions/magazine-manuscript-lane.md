## 관문을 만든 사고 — 이미 새어 나갔다

`after-holiday-body-ache` 본문에 ChatGPT 인용 마커가 그대로 들어가 **production 에 공개됐다.**

```
… 며칠 동안 해 왔던 겁니다. :contentReference[oaicite:0]{index=0}
```

당시 변환기의 금지 목록(표 · 코드블록 · h1 · h4 · 이미지 · 링크 · HTML · 번호목록)은 이 형태를 걸러 내지 못했다.
화면에 상태를 보여 주는 함수는 있었지만 **저장을 막지는 않았다** — 사람이 그 줄을 읽지 않으면 그대로 흘러갔다.
그래서 판정을 쓰기 앞으로 옮겼다. "저장 금지"는 쓰기 전에만 성립한다.

- `articles.ts` 의 본문은 `dea1c7a`(#299)에서 고쳤다. 그 글의 `draft.md` 에는 마커가 아직 남아 있고, 관문은 그것을 정상적으로 막는다(runbook §9).

## 지금도 유효한 것 — 관문이 막는 것

`scripts/lib/magazine-manuscript-guard.mjs` 가 판정만 한다. 원고를 고치지 않는다. 막히면 파일이 생기지 않는다.

| 코드 | 무엇 |
|---|---|
| `EMPTY` | 빈 원고 |
| `NO_FRONTMATTER` · `FRONTMATTER_UNCLOSED` | `---` 로 시작하지 않거나 닫히지 않음 |
| `META_MISSING` | `title` · `description` · `cluster` 누락 |
| `TOO_SHORT` | 본문 1,200자 미만 (당시 실제 원고는 1,669~2,200자) |
| `NOT_KOREAN` | 한글 비율 30% 미만 (당시 실제 원고는 96~99%) |
| `CONTAMINATED` | `:contentReference` · `oaicite` · `【…†…】` · `turn0search1` · zero-width |
| `NO_SECTION` | `##` 소제목이 하나도 없음 |

지금의 정확한 코드와 임계값은 위 모듈이 정본이다. 이 표는 2026-09-02 의 판이다.

### 일부러 넣지 않은 규칙 — 오탐 방지

**대화체 인사**("물론입니다 / 아래 원고입니다")를 본문 단어로 잡지 않는다.
인사가 붙으면 원고가 `---` 로 시작하지 않아 `NO_FRONTMATTER` 가 이미 잡는다.
단어로 잡으려 하면 오탐이 난다 — 실제 원고에 `"여기서 중요한 것은…"` 이 있다.

🔴 **관문의 오탐은 막지 못하는 것보다 나쁘다.** 공급이 통째로 멈춘다.

### 이 근거를 지키는 검사

| 무엇을 | 어디서 |
|---|---|
| 정상 원고는 통과하고 오염된 원고는 여전히 막힌다 · 추적된 표본으로만 돈다 | `scripts/magazine-auto-register-check.mjs` 의 원고 관문 절 · 표본 `scripts/__fixtures__/magazine/` |
| 응답 회수가 실패했을 때 저장 0 · 전송 불명과 내용 실패를 가른다 | `scripts/magazine-m3a-check.mjs` |
| vNext 원고의 검증 · 부분 수리 · 전체 재생성 | runbook §0.0B.3 · `scripts/magazine-vnext-produce-check.mjs` |

## 2026-09-15 에 드러난 것 — "한 줄이면 켜진다"는 틀렸다

9-02 판은 "켤 때 고치는 것은 plist 한 줄"이라고 적었다. 사실이 아니었다. 그 두 인자를 넣어도 job 이 돌지 않았다.

1. plist 가 symlink 면 TCC 가 읽기를 거부해 **등록조차 되지 않았다**(2026-09-03 이후 12일 정지).
2. `gh` 가 launchd PATH 에 없어 **push 뒤에** PR 실패를 알게 되는 순서였다.
3. main 복귀 코드가 없어 첫 성공 회차 뒤 매일 `NOT_ON_MAIN` 으로 멈췄다.
4. write 실패가 `exit 0` 으로 숨겨졌다.

**"한 줄"이라는 말이 점검을 건너뛰게 만들었다.** 넷 모두 runbook §1 에 근인과 함께 적혀 있고 회귀 테스트가 지킨다.
