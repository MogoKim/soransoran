## 이 글의 자리

- 단발 글 (시리즈 아님)
- 클러스터: 마음
- 위험 등급: MEDIUM — 왜 기운이 없는지 설명하는 데까지. 진단·치료는 다루지 않는다
- 계절: 9~10월 환절기에 읽는 글이다. 공개 시점이 그 시기다

## 검색 의도

```
환절기 무기력 / 가을 타는 이유 / 계절 바뀔 때 피곤함 / 환절기 우울 / 요즘 기운이 없어요
```

**"왜 하필 이맘때 이러는지"를 알고 싶어 들어온다.**
게으른 것도 병도 아니라는 확인을 원하고, 오늘 해볼 만한 것을 찾는다.

## 대상 독자

40대 중반~60대 중반 여성. 계절이 바뀌는 시기를 여러 번 겪어 온 사람이다.

- 아침에 일어나기가 유독 힘들다
- 할 일은 그대로인데 **몸이 안 따라 준다**
- 이유 없이 가라앉는 날이 늘었다
- 예년에도 그랬던 것 같은데 **올해는 더한 것 같아** 신경이 쓰인다

## 도입에서 해야 할 것

첫 두세 문장 안에 "그럴 만하다"를 준다.
설명부터 시작하지 않는다. **장면부터 쓴다.**

아침 공기가 달라진 걸 느끼며 일어나는데, 몸이 이불에서 잘 떨어지지 않는 그 장면.

## 글 구조 (h2 5개)

1. **계절이 바뀔 때 몸이 겪는 일**
   일조량·기온·일교차가 몸의 리듬에 영향을 준다는 설명.
   단정하지 말고 "이야기됩니다" 수준으로. 의학 용어를 쓰지 않는다.

2. **이맘때 자주 나타나는 모습**
   목록 5개 안팎.
   (아침에 일어나기 힘듦 / 낮에 졸림 / 입맛 변화 / 의욕 저하 / 사소한 일에 예민해짐)
   "전부 해당하는 건 아니다"를 반드시 붙인다.

3. **나이 탓인지 계절 탓인지**
   이 글의 핵심. 두 가지가 겹칠 수 있다는 정도까지만.
   **갱년기 때문이라고 단정하지 않는다.** 어느 쪽인지 가르지 않는다.

4. **오늘 해볼 수 있는 것**
   부담 없는 것 4개 안팎.
   (아침에 햇빛 보기 / 잠자리에 드는 시간만 고정하기 / 짧게 걷기 / 따뜻한 것 먹기)
   전부 하라고 하지 않는다. "하나만 골라 일주일" 정도의 톤.

5. **혼자만 그런 게 아닙니다**
   같은 시기에 비슷하게 겪는 사람이 많다는 감각을 준다.
   여기서 자연스럽게 커뮤니티로 넘긴다.

## 반드시 그대로 넣을 문장 5개

**토씨 하나 바꾸지 마세요.** 창업자가 검수할 때 원문과 대조하는 문장입니다.
다듬거나 합치거나 순서를 바꾸면 검수 대조가 실패해 원고를 다시 받아야 합니다.

```
1. 계절이 바뀌는 시기에 몸의 리듬이 흔들린다고 이야기됩니다.
2. 어떤 모습으로 나타나는지는 사람마다 다릅니다.
3. 기운이 없다고 해서 게으른 것이 아닙니다.
4. 다만 가라앉는 기분이 몇 주 넘게 이어진다면 병원에서 확인해 보시는 편이 좋습니다.
5. 계절 탓인지 다른 이유인지는 한 가지로 잘라 말하기 어렵습니다.
```

각 문장이 들어갈 자리: 1→h2 1 / 2→h2 2 / 3→h2 3 / 4→h2 3 끝 또는 인용 / 5→h2 3
