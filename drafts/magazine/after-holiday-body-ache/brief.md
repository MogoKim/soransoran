# 원고 지시서 — 명절 지나고 나면 왜 더 아플까요?

> 이 문서는 ChatGPT 에게 넘기는 지시서다. 산출물은 **마크다운 원고**다.

## 출력 규칙 — 반드시 지킨다

**아래 형식으로만 출력하세요. 설명·인사·요약·후기를 붙이지 마세요.
최종 원고 전체만 출력합니다.**

````
---
title: 명절 지나고 나면 왜 더 아플까요?
description: (90~120자. 직접 쓴 요약)
cluster: family
medical: true
---

첫 문단입니다. 한 문단은 2~3문장으로 씁니다.

## 소제목

문단.

> 짚어둘 문장은 인용 표시로 씁니다.

- 목록 항목
- 목록 항목

````

## 이 글의 자리

- 단발 글 (시리즈 아님)
- 클러스터: 가족
- 위험 등급: MEDIUM — 몸이 힘든 이유를 설명하는 데까지. 진단·치료는 다루지 않는다
- 계절: 추석 2~4주 전에 공개된다. 명절이 **아직 오지 않은** 시점에 읽는 글이다

## 검색 의도

```
명절 후 몸살 / 명절 지나고 몸이 아파요 / 추석 후 피로 / 명절 증후군 / 명절 끝나고 온몸이 쑤심
```

**"왜 이렇게까지 아픈지"를 알고 싶어 들어온다.**
꾀병이 아니라는 확인, 그리고 다음 명절을 조금 덜 힘들게 보낼 방법을 찾는다.

## 대상 독자

40대 중반~60대 중반 여성. 명절마다 음식 준비와 손님 치르기를 해 온 사람이다.

- 명절 당일보다 **끝나고 며칠 뒤**에 더 아프다
- 허리·어깨·무릎이 한꺼번에 쑤신다
- 잠을 자도 개운하지 않고 기운이 안 돌아온다
- "나이 들어서 그런가" 싶으면서도 **말하면 유난 떠는 것 같아** 삼킨다

## 도입에서 해야 할 것

첫 두세 문장 안에 "그럴 만하다"를 준다.
설명부터 시작하지 않는다. **장면부터 쓴다.**

명절이 끝나고 집이 조용해진 다음 날 아침, 몸을 일으키는데
어깨부터 허리까지 한 번에 오는 그 느낌.

## 글 구조 (h2 5개)

1. **왜 끝나고 나서 더 아플까요**
   긴장이 풀린 뒤에 통증과 피로가 몰려오는 흐름을 설명한다.
   단정하지 말고 "그런 경우가 많습니다" 수준으로.

2. **몸이 어디부터 힘든지**
   반복 동작이 쌓이는 부위를 목록 5개 안팎.
   (오래 서 있기 / 쪼그려 앉기 / 무거운 그릇 옮기기 / 같은 자세로 다듬기 / 설거지)
   "사람마다 다르다"를 반드시 붙인다.

3. **나이 탓만은 아닙니다**
   이 글의 핵심. 회복이 느려지는 것은 자연스러운 변화이지
   몸이 잘못된 것이 아니라는 안심을 준다.
   갱년기 시기와 겹치면 더 힘들 수 있다는 정도까지만.

4. **끝나고 며칠은 이렇게**
   부담 없는 회복 방법 4개 안팎.
   (하루는 아무 일정도 잡지 않기 / 따뜻한 물로 씻기 / 가벼운 걷기 / 잠을 평소보다 넉넉히)
   전부 하라고 하지 않는다. "하나만 골라도 됩니다" 정도의 톤.

5. **다음 명절을 위해 미리**
   지금이 명절 전이라는 점을 살린다. 미리 나눠 두거나 줄일 수 있는 것을 짚는다.
   여기서 자연스럽게 커뮤니티로 넘긴다.

## 반드시 그대로 넣을 문장 5개

**토씨 하나 바꾸지 마세요.** 창업자가 검수할 때 원문과 대조하는 문장입니다.
다듬거나 합치거나 순서를 바꾸면 검수 대조가 실패해 원고를 다시 받아야 합니다.

```
1. 긴장이 풀린 뒤에야 피로가 몰려오는 경우가 많습니다.
2. 어디가 먼저 힘든지는 사람마다 다릅니다.
3. 회복이 예전보다 더디게 느껴지는 것은 이상한 일이 아닙니다.
4. 다만 통증이 며칠이 지나도 가라앉지 않는다면 병원에서 확인해 보시는 편이 좋습니다.
5. 명절 노동을 당연하게 여기지 않아도 됩니다.
```

각 문장이 들어갈 자리: 1→h2 1 / 2→h2 2 / 3→h2 3 / 4→h2 3 끝 또는 인용 / 5→h2 5

## 절대 쓰지 말 것

```
🚫 명절 혐오 톤 — "명절은 없어져야" "시댁 때문에" 같은 방향으로 몰지 않는다
🚫 가족 갈등 과장 — 며느리·시어머니 대립 구도를 만들지 않는다
🚫 특정 진단명 — "근막통증증후군" "디스크" "관절염" 같은 병명으로 단정하지 않는다
🚫 치료법·약·파스·영양제·마사지기 등 제품 언급
🚫 "반드시" "치료됩니다" "낫습니다" "원인입니다" "효과적입니다"
🚫 "시니어" "어르신" "노인" "실버"
🚫 출처 없는 통계 — "주부의 70%가" 같은 수치
🚫 "~에 대해 알아보겠습니다" "결론적으로" 같은 AI 문형
```

**명절을 나쁜 것으로 그리지 않는다.** 힘든 것은 힘들다고 인정하되,
가족이나 명절 자체를 비난하는 글이 되면 안 된다. 몸과 회복이 이 글의 주제다.

## 톤

- 존댓말. 상담해 주는 톤이 아니라 **옆에서 같이 이야기하는** 톤
- 문단은 2~3문장. 길이를 일부러 들쭉날쭉하게
- 목록은 3곳을 넘기지 않는다. 나머지는 산문
- 전문 용어를 쓰면 바로 풀어쓴다
- 소리 내어 읽었을 때 어색하면 고친다

