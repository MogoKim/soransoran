## 이 글의 자리

**이 글은 몸 상태를 판단하지 않는다.** 제도와 상담 준비만 다룬다. 그 선을 넘지 않는 것이

## 검색 의도

이 글을 찾는 사람은 **검진 안내문을 받았거나 주변에서 이야기를 듣고** 검색한다.
증상이 있어서 오는 것이 아니다.

```
골다공증 검사 언제           시기 자체를 모른다        ← 주 의도
골다공증 검사 나이           몇 살부터인지 궁금하다
폐경 후 골다공증 검사        폐경과 연결해 검색한다    ← 이 글의 핵심 자리
국가검진 골밀도              검진 항목에 있는지 확인
골밀도 검사 주기             한 번 받고 다음은 언제인지
```

**이 글이 답할 한 가지**: 골다공증 검사를 언제 이야기 꺼내면 되는지,
그리고 왜 "몇 살부터"를 이 글이 정해 주지 않는지를 알려 준다.

> ⚠️ **이 주제의 난이도가 여기 있다.** 검색 의도는 "몇 살부터인지 알려 달라" 인데
> 큐 금지선은 "시기·주기를 단정하지 마라" 다. 나이를 숫자로 적는 순간 선을 넘는다.
> **시기를 정해 주는 글이 아니라, 상담에서 꺼낼 기준을 정리하는 글이다.**

## 대상 독자

50대~60대 중반 여성. 이 주제에서 그 사람이 겪는 장면은 이렇다.

- 검진 안내문에 골밀도 검사가 있는데 받아야 하는 건지 모르겠다
- 폐경이 지나고 나서 뼈 이야기를 자주 듣는데 뭘 해야 할지 모르겠다
- 친구는 받았다는데 나는 아직인 것 같아 늦은 건가 싶다
- 검사를 받고 나면 무슨 이야기를 듣게 되는지 몰라 미루고 있다

## 도입에서 해야 할 것

설명으로 시작하지 않는다. **검진 안내문 앞에서 멈춘 장면**으로 연다.

받아야 하는지 아닌지 몰라 접어 둔 마음을 2~3문장으로 그린다.
불안을 키우지 않는다 — 뼈가 약해진다는 경고가 아니라 **흔한 망설임**이라는 톤이다.

## 글 구조 (h2 5개)

**1. 검사 이야기를 언제 꺼내게 되나요**
검진 안내문·주변 이야기·폐경 이후처럼 이 검사를 떠올리게 되는 계기를 짚는다.
범위: 계기까지. 금지: 나이·시기를 숫자로 제시하지 않는다.

**2. 왜 하나의 시기를 정해 말하기 어려운가**
폐경 시점·가족력·복용 중인 약·체중 같은 것이 함께 고려된다고만 적는다.
**여기가 이 글의 중심이다.** 범위: 고려된다는 사실까지. 금지: 각 요인의 영향 크기, 위험도 계산.

**3. 국가건강검진에서는 어떻게 되어 있나요**
공단 검진에 골밀도 검사가 포함되는 대상이 정해져 있다는 것과, **본인 대상 여부는
공단 안내에서 확인한다**는 경로만 적는다. 금지: 연령·주기를 숫자로 옮겨 적지 않는다.

**4. 검사를 받으면 어떤 이야기를 하게 되나요**
결과를 두고 의료진과 이야기를 나눈다는 정도. **여기에 진료 권고 문장을 둔다**
(§4.4 "증상 설명 직후"). 금지: 수치·T점수·정상 범위, 결과 해석, 치료 언급.

**5. 상담 전에 정리해 두면 도움이 되는 것**
폐경 시기·가족 중 골절 이력·복용 중인 약처럼 물어보면 답하게 되는 것들.
범위: 준비 목록까지. 금지: 자가 위험도 체크리스트로 굳히지 않는다.

## 반드시 그대로 넣을 문장 5개

원고에 **토씨 그대로** 들어가야 한다. `review.ts` 의 `riskSentences` 와 문자열이 같아야 한다.

1. 검진 안내문에서 골밀도 검사를 보고도 받아야 하는 것인지 몰라 그대로 접어 두게 되는 경우가 있습니다.
2. 검사를 언제 받는 것이 좋은지는 폐경 시점과 가족력, 복용 중인 약처럼 여러 가지를 함께 보기 때문에 하나의 나이로 말하기는 어렵습니다.
3. 국가건강검진에 골밀도 검사가 포함되는 대상이 정해져 있으므로, 올해 본인이 해당하는지는 건강보험공단 안내에서 확인할 수 있습니다.
4. 검사 결과를 두고 무엇을 더 살펴볼지는 진료에서 의료진과 함께 이야기하게 됩니다.
5. 폐경 시기와 가족 중 골절이 있었는지, 지금 드시는 약이 있는지를 적어 가시면 상담에서 이야기가 수월해집니다.

## 절대 쓰지 말 것

### 이 주제의 금지선 — 검사 시기·수치를 정하지 않는다

```
🚫 시기 단정   50세부터 받으세요 · 폐경 후 바로 받아야 합니다 · 2년마다 받습니다
              몇 살부터 · 몇 년 주기 — 숫자로 적지 않는다
🚫 수치 해석   T점수 · 골밀도 수치 · 정상 범위 · -2.5 · 골감소증입니다
🚫 검사 강요   꼭 받으세요 · 반드시 받아야 합니다 · 미루면 안 됩니다
🚫 진단 단정   골다공증입니다 · 뼈가 약해졌습니다
```

### D5 — 진료과를 정해 주는 문장 (자동 QA FAIL)

```
🚫 산부인과에 가야 합니다 · 정형외과가 정답입니다 · ~과를 추천합니다
```

과 이름을 쓰는 것 자체는 괜찮다. 막는 것은 **독자 대신 고르는 문장**이다.
쓸 수 있는 형태는 관찰형("~하는 경우가 많습니다")·허용형("~해도 됩니다")이다.

### D7 — 치료를 권하거나 말리는 문장 (자동 QA FAIL)

```
🚫 칼슘제를 드세요 · 비타민D를 챙기세요 · 골다공증 약을 받으세요
🚫 호르몬 치료를 받으세요 · ~는 위험합니다
```

**치료·영양제는 이 글의 범위가 아니다.** 결과를 받은 뒤의 이야기는 의료진의 몫이다.

### D8 — 비용을 숫자로 말하는 문장 (자동 QA FAIL)

```
🚫 검사 비용은 ~원입니다 · 검사비가 ~원 정도 듭니다
```

검사비는 병원·보험 적용에 따라 달라진다. 숫자를 적으면 그 자체가 틀린 정보가 된다.

### 그 밖에

```
🚫 공포 조장    지금 안 받으면 늦습니다 · 골절로 이어집니다
🚫 기관 지목    특정 병원·의원·검진센터·브랜드명
🚫 발행 전 글   checkup-items-50s · after-menopause-body 를 가리키는 표현
```

## 4050 여성 커뮤니티 정체성

이 글은 **검진 안내 페이지가 아니다.** "받아야 하는 건지 몰라 접어 둔 마음"에서 출발해,
같은 안내문을 받아 본 사람들이 모인 곳으로 이어지는 글이다.

- 정보를 주되 **결정을 대신하지 않는다.** 결정은 독자와 의료진의 몫이다
- 뼈를 두려운 것으로 그리지 않는다. 나이를 문제로 규정하지 않는다
- "나만 늦었나" 싶은 마음을 "다들 여기서 멈춘다" 로 바꿔 준다
- 전문 용어는 나오는 자리에서 바로 풀어쓴다
