## 검색 의도

이 글을 찾는 사람은 **검진 안내문을 받아 들고** 검색한다.
증상이 있어서 오는 것이 아니라, 종이에 적힌 이름들이 낯설어서 온다.

```
50대 건강검진 항목        무엇을 보게 되는지 모른다      ← 주 의도
건강검진 항목 추천        골라 달라는 마음
50대 여성 건강검진        내 나이·성별 기준이 궁금하다   ← 이 글의 핵심 자리
국가건강검진 항목         공단 검진에 뭐가 들어 있나
건강검진 뭐 받아야 하나   결정을 미루고 있다
```

**이 글이 답할 한 가지**: 안내문에 적힌 항목이 어떻게 정해지는지,
그리고 왜 "이걸 받으세요" 를 이 글이 정해 주지 않는지를 알려 준다.

> ⚠️ **이 주제의 난이도가 여기 있다.** 검색 의도는 "골라 달라" 인데
> 큐 금지선은 "항목 사실관계 검증 필수" 다. 항목을 목록으로 정해 주는 순간
> 그 목록의 사실 책임을 이 글이 지게 된다.
> **항목을 골라 주는 글이 아니라, 내 항목이 어떻게 정해지고 검진에서 무엇을
> 물어보면 되는지를 정리하는 글이다.**

## 대상 독자

50대 전반 여성. 이 주제에서 그 사람이 겪는 장면은 이렇다.

- 안내문을 받았는데 이름만 봐서는 무슨 검사인지 모르겠다
- 친구가 받은 항목이 내 안내문에는 없어서 빠진 건가 싶다
- 추가로 받을 수 있다는 이야기를 들었는데 뭘 골라야 할지 모르겠다
- 뭘 물어봐야 할지 몰라 그냥 하라는 대로 받고 나온다

## 도입에서 해야 할 것

설명으로 시작하지 않는다. **안내문을 펼쳐 놓고 멈춘 장면**으로 연다.

이름들이 낯설어 접어 둔 마음을 2~3문장으로 그린다.
불안을 키우지 않는다 — 병을 놓친다는 경고가 아니라 **흔한 망설임**이라는 톤이다.

## 글 구조 (h2 5개)

**1. 안내문을 받고 한 번 멈추게 되는 자리**
이름이 낯설어 접어 두게 되는 장면을 짚는다.
범위: 장면까지. 금지: 여기서는 아직 항목 이름을 꺼내지 않는다.

**2. 항목이 사람마다 달라 보이는 이유**
나이·성별·지금까지의 검진 이력처럼 여러 가지가 함께 반영된다고만 적는다.
**여기가 이 글의 중심이다.** 범위: 함께 본다는 사실까지.
금지: 어떤 조건에서 어떤 항목이 나오는지 규칙으로 적지 않는다.

**3. 안내문에서 자주 보이는 이름들**
낯설게 느껴지는 이름 서너 개를 들고, 각각이 대체로 무엇을 보는 것으로 이야기되는지
**한 줄씩만** 짚는다. 목록은 이 h2 에서 한 번만 쓴다.
범위: 이름을 알아볼 수 있게 하는 데까지. 금지: 받아야 할 항목으로 읽히게 쓰지 않는다.
누가 대상인지, 언제·몇 년마다 받는지는 여기서 말하지 않는다.

**4. 내 항목은 어디서 확인하나요**
본인에게 안내된 항목은 **안내문과 공단 안내에서 확인한다**는 경로를 적는다.
낯선 이름은 진료에서 물어봐도 된다는 것도 여기 둔다. **진료 권고 문장이 이 자리다**
(§4.4 "증상 설명 직후"). 금지: 연령·주기·대상 기준을 이 글이 옮겨 적지 않는다.

**5. 검진 전에 적어 두면 도움이 되는 것**
요즘 달라진 몸의 변화, 드시는 약, 가족 중 있었던 병처럼 물어보면 답하게 되는 것들.
범위: 준비 목록까지. 금지: 자가 위험도 체크리스트로 굳히지 않는다.

## 반드시 그대로 넣을 문장 5개

원고에 **토씨 그대로** 들어가야 한다. `review.ts` 의 `riskSentences` 와 문자열이 같아야 한다.

1. 검진 안내문을 받고도 어떤 항목을 확인해야 하는지 몰라 그대로 서랍에 넣어 두게 되는 경우가 있습니다.
2. 검진에서 무엇을 보게 되는지는 나이와 성별, 지금까지의 검진 이력에 따라 달라지기 때문에 하나의 목록으로 말하기는 어렵습니다.
3. 올해 본인에게 어떤 항목이 안내되었는지는 손에 든 안내문과 건강보험공단 안내에서 확인할 수 있습니다.
4. 안내문에 낯선 이름이 보이면 무엇을 보는 검사인지 진료에서 먼저 물어보셔도 됩니다.
5. 요즘 달라진 몸의 변화와 지금 드시는 약을 적어 두시면 검진에서 이야기를 꺼내기가 수월해집니다.

```

🚫 대상 단정   ~세부터 받습니다 · 폐경 후에는 ~를 받게 됩니다 · ~인 사람이 대상입니다
🚫 수치 해석   정상 범위 · 정상 수치 · 수치가 높으면 · 재검사 대상입니다
🚫 주기 단정   2년마다 · 해마다 받습니다 · 몇 년에 한 번
```

#### 이름을 짚는 문장은 이렇게 쓴다

항목 이름을 아예 안 쓰면 안내문을 든 사람에게 아무 도움이 되지 않는다.
**이름을 알아보게 하는 데까지는 쓰고, 판단은 넘긴다.**

```
✅ 쓸 수 있다   골밀도 검사는 뼈가 얼마나 성긴지 살펴보는 것으로 이야기됩니다
               유방촬영은 가슴 쪽을 사진으로 확인하는 검사로 알려져 있습니다
🚫 못 쓴다      골밀도 검사는 골다공증을 진단하는 검사입니다
               유방촬영은 50세부터 2년마다 받는 항목입니다
```

차이는 둘이다 — **단정하지 않는 어미**로 쓰고, **누가 언제 받는지를 붙이지 않는다.**
목록은 이름과 한 줄 설명까지다. 받아야 할 것들의 체크리스트로 굳히지 않는다.

⚠️ 여기 적는 한 줄은 **창업자가 사실관계를 확인하는 대상**이다(큐 금지선 "항목 사실관계
검증 필수"). 확신이 서지 않는 이름은 아예 넣지 않는 편이 낫다.

### 제도를 단정하지 않는다

```
🚫 국가건강검진에는 ~가 포함됩니다 · ~세부터 대상입니다 · ~는 대상이 됩니다
```

공단 검진 기준은 해마다 바뀐다. **이 글은 기준을 옮겨 적지 않고 확인 경로만 알려 준다.**
쓸 수 있는 형태는 "안내문과 공단 안내에서 확인할 수 있습니다" 다.

### D5 — 진료과를 정해 주는 문장 (자동 QA FAIL)

```
🚫 산부인과에 가야 합니다 · ~과부터 가세요 · ~과를 추천합니다
```

이 글은 진료과를 다루지 않는다. 과 이름을 굳이 꺼내지 않는다.

### D7 — 치료를 권하거나 말리는 문장 (자동 QA FAIL)

```
🚫 영양제를 드세요 · 약을 받으세요 · ~는 위험합니다
```

**치료·영양제는 이 글의 범위가 아니다.** 검진 이후의 이야기는 의료진의 몫이다.

### D8 — 비용을 숫자로 말하는 문장 (자동 QA FAIL)

```
🚫 검사비는 ~원입니다 · 추가 항목은 ~만 원 정도 듭니다
```

검진비는 기관·보험 적용에 따라 달라진다. 숫자를 적으면 그 자체가 틀린 정보가 된다.
**금액은 한 번도 쓰지 않는다.**

### 그 밖에

```
🚫 공포 조장    지금 안 받으면 늦습니다 · 놓치면 큰 병이 됩니다
🚫 기관 지목    특정 병원·의원·검진센터·브랜드명. 붙여 쓴 상호명 형태도 쓰지 않는다
🚫 발행 전 글   which-clinic-menopause 를 가리키는 표현
```

## 4050 여성 커뮤니티 정체성

이 글은 **검진 안내 페이지가 아니다.** "안내문을 받고도 뭘 봐야 할지 몰라 접어 둔 마음"에서
출발해, 같은 종이를 받아 본 사람들이 모인 곳으로 이어지는 글이다.

- 정보를 주되 **결정을 대신하지 않는다.** 결정은 독자와 의료진의 몫이다
- 검진을 두려운 것으로 그리지 않는다. 나이를 문제로 규정하지 않는다
- "나만 모르나" 싶은 마음을 "다들 여기서 멈춘다" 로 바꿔 준다
- 낯선 이름은 이름 그대로 두고, 묻는 방법을 알려 준다
