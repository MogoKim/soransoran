## 이 글의 자리

- 단발 글 (시리즈 아님)
- 클러스터: 갱년기 증상
- 위험 등급: MEDIUM — 왜 아픈지 설명하고 무리를 덜어 주는 데까지.
  **진단명과 치료법은 다루지 않는다**
- 계절: 추석 2~4주 전에 공개된다. 명절 음식을 **아직 하기 전**에 읽는 글이다

## 검색 의도

```
명절 후 손목 통증 / 전 부치고 손목 아픔 / 손목 시큰거림 / 명절 손목 / 손목 저림
```

**"왜 손목만 이렇게 아픈지"를 알고 싶어 들어온다.**
병원에 갈 정도인지 아닌지를 가늠하고 싶고, 미리 덜 아프게 할 방법을 찾는다.

## 대상 독자

40대 중반~60대 중반 여성. 명절마다 음식 준비를 맡아 온 사람이다.

- 전을 부치거나 나물을 무치고 나면 **손목부터 시큰거린다**
- 다음 날 병뚜껑을 못 열거나 물건을 놓치기도 한다
- 예전에는 하루 자면 나았는데 요즘은 **며칠씩 간다**
- 다들 그러려니 해서 말을 꺼내기 어렵다

## 도입에서 해야 할 것

첫 두세 문장 안에 "그럴 만한 이유가 있다"를 준다.
설명부터 시작하지 않는다. **장면부터 쓴다.**

프라이팬 앞에 오래 서서 같은 손놀림을 반복하다가,
다음 날 아침 수도꼭지를 돌리는데 손목이 찌릿한 장면.

## 글 구조 (h2 5개)

1. **손목에 무엇이 쌓이는 걸까요**
   같은 동작을 오래 반복할 때 손목에 부담이 쌓이는 흐름을 설명한다.
   **해부학 용어와 병명을 쓰지 않는다.** "이야기됩니다" 수준으로.

2. **명절에 특히 부담이 되는 동작**
   목록 5개 안팎.
   (프라이팬 뒤집기 / 반죽 젓기 / 무거운 그릇 들기 / 오래 칼질하기 / 손빨래나 설거지)
   "사람마다 다르다"를 반드시 붙인다.

3. **요즘 더 오래 가는 것 같다면**
   이 글의 핵심 중 하나. 회복이 느려지는 변화가 이 시기와 겹칠 수 있다는 정도까지만.
   **갱년기 때문이라고 단정하지 않는다.** 가능성으로만 언급한다.

4. **미리 덜 아프게 하는 법**
   부담 없는 것 4개 안팎.
   (한 자세를 오래 하지 않기 / 중간에 손목 털어 주기 / 무거운 그릇은 두 손으로 /
    앉아서 할 수 있는 일은 앉아서)
   **치료법·보조기·파스·찜질기 같은 처치와 제품을 제시하지 않는다.**

5. **혼자 다 하지 않아도 됩니다**
   일을 나누는 이야기로 넘어간다. 지금이 명절 전이라는 점을 살린다.
   여기서 자연스럽게 커뮤니티로 넘긴다.

## 반드시 그대로 넣을 문장 5개

**토씨 하나 바꾸지 마세요.** 창업자가 검수할 때 원문과 대조하는 문장입니다.
다듬거나 합치거나 순서를 바꾸면 검수 대조가 실패해 원고를 다시 받아야 합니다.

```
1. 같은 동작을 오래 반복하면 손목에 부담이 쌓인다고 이야기됩니다.
2. 어떤 동작이 더 힘든지는 사람마다 다릅니다.
3. 회복이 예전보다 더디게 느껴지는 것은 이상한 일이 아닙니다.
4. 저리거나 힘이 빠지는 느낌이 이어진다면 병원에서 확인해 보시는 편이 좋습니다.
5. 명절 음식을 혼자 다 맡지 않아도 됩니다.
```

각 문장이 들어갈 자리: 1→h2 1 / 2→h2 2 / 3→h2 3 / 4→h2 3 끝 또는 인용 / 5→h2 5
