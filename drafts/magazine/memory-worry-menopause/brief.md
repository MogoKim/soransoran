## 검색 의도

이런 검색어로 들어온다.

- "50대 기억력 감퇴"
- "갱년기 건망증 심해요"
- "이름이 자꾸 안 떠올라요"
- "치매 초기 증상인가요"
- "요즘 자꾸 깜빡해요"
- "갱년기 뇌 안개"

이 글이 답할 한 가지: 지금 자주 겪는 깜빡임이 이 시기에 흔히 이야기되는 흐름인지, 병원에 가야 할 신호인지 스스로 감을 잡게 돕는다. 진단은 하지 않는다.

## 대상 독자

50대 전반 여성.

- 냉장고 문을 열고 왜 열었는지 잊은 적이 있다
- 오래 알던 사람 이름이 순간 떠오르지 않는다
- 대화 도중 하려던 말이 중간에 사라진다
- 리모컨·안경·차 키를 하루에도 몇 번씩 찾는다

## 도입에서 해야 할 것

"갱년기가 오면 기억력이 떨어진다" 같은 설명으로 시작하지 않는다.
독자가 최근에 겪었을 만한 짧은 장면 하나를 먼저 보여준다.
"혹시 나만 그런가" 라는 마음이 조금 가벼워지도록, 감정을 진단으로 옮기지 않는다.

## 글 구조

h2 5개로 간다. 아래는 각 h2 의 다룰 범위와 금지선이다.

**이 글에서 다루지 않는 것**
- 치매·경도인지장애 진단 기준과 검사 종목 (의료 정보 사이트의 몫)
- 우울·무기력에서 오는 기억 저하 (별도 글 `no-motivation-50s`)
- 수면 습관 전반 (별도 매거진 예정)
- 특정 보조제·건강기능식품 추천

### h2 1. 요즘 자꾸 놓치는 순간들
독자가 어제·오늘 겪었을 만한 장면을 3~4개 보여준다. 판단은 아직 하지 않는다.
금지: "이건 치매의 시작이다" 같은 단정, 자가진단 유도.

### h2 2. 갱년기와 기억, 무엇이 달라진다고 이야기되나
호르몬 변화가 집중과 기억 인출에 영향을 준다고 이야기되는 흐름을 두세 문단으로. "사람마다 다르다" 를 곁들인다.
금지: 수치·백분율 인용, 특정 호르몬·특정 뇌 부위의 확정적 인과.

### h2 3. 흔한 신호와 결이 다른 신호
흔히 이야기되는 신호(이름·용건·물건 잊음)와, 결이 다른 신호(같은 질문을 짧은 시간 안에 반복함·익숙한 길을 잃음·잊었다는 사실 자체를 놓침)를 구분한다. 위협 톤이 아니라 안내 톤으로.
금지: 체크리스트로 개수를 세게 만드는 문장, "3개 이상이면 위험" 식 유도.

### h2 4. 오늘부터 해볼 수 있는 작은 것
잠 시간 지키기, 하려던 일 짧게 적어두기, 카페인·술 시간대 조절, 옆 사람과 소리 내어 이야기하기 정도만.
금지: 특정 보조제·건강기능식품 추천, "이것만 하면 된다" 식 단정.

### h2 5. 병원에 가볼 만한 때
3번의 결이 다른 신호가 반복되거나 일상에 지장이 크거나 혼자 판단이 어려울 때 어떤 진료과에 이야기해볼 수 있는지 안내한다. 담담한 톤으로.
금지: 특정 병원·특정 약 이름, "지금 당장 가야 한다" 식 재촉.

## 반드시 그대로 넣을 문장

원고에 아래 5문장을 토씨 하나 다르지 않게 넣는다. review 의 riskSentences 가 이 문장을 문자열로 검사한다.

1. 이름이 갑자기 떠오르지 않고, 하려던 말이 중간에 사라지는 순간이 잦아지는 시기예요.
2. 이 시기 많은 분들이 비슷한 경험을 이야기하지만, 이유는 사람마다 다를 수 있어요.
3. 잊는 순간이 있는 것과, 잊었다는 사실 자체를 놓치는 것은 결이 다르다고 이야기됩니다.
4. 혼자 판단이 어려울 때는 가까운 병원에서 진료를 받아 지금 상태를 확인해 두는 것이 마음이 편해집니다.
5. 혼자 삼키기보다 비슷한 시기를 지나고 있는 사람들과 이야기를 나누면, 걱정의 크기가 줄어들기도 해요.

## 절대 쓰지 말 것

공통 금지에 더해, 이 주제에서 특히 위험한 것들.

- 진단명 단정: "치매입니다" "알츠하이머입니다" "경도인지장애입니다"
- 위협 조장: "이대로 두면 치매로 이어집니다" "지금이 시작입니다" "곧 진행됩니다"
- 특정 보조제·성분 추천: 은행잎 추출물, 오메가3, 뇌영양제, 홍삼, "이것만 먹으면"
- 확정형 예방·완치·보장: "이렇게 하면 예방됩니다" "완치됩니다" "무조건 좋아집니다"
- 자가진단 유도: "이 중 3개 이상이면 병원에 가야 합니다" 같은 체크리스트 강요
- 나이 낙인: "나이 들면 다 그래요" 로 뭉개기 (진지한 신호도 있음)
