이 글의 중심은 **"어디부터"** 다.
재취업이 되느냐 마느냐를 논하지 않는다. **첫 걸음의 순서**를 이야기한다.

## 검색 의도

```
50대 재취업 / 50대 일자리 어디서 / 경력단절 재취업 / 나이 많아도 뽑아주나 / 재취업 시작
```

**"막막한데 뭐부터 해야 하는지"** 를 알고 싶어 들어온다.
구인 사이트를 열어 봤지만 무엇을 검색해야 할지조차 모르겠는 상태다.

## 대상 독자

50대 전반 여성. 일을 다시 시작해 보려는 사람이다.

- 오래 쉬었거나, 하던 일을 그만둔 지 시간이 좀 지났다
- 이력서를 마지막으로 쓴 게 언제인지 기억이 잘 안 난다
- 주변에 물어보기가 조심스럽다
- "나이 때문에 안 될 것"이라는 말을 이미 여러 번 들었다

## 도입에서 해야 할 것

첫 두세 문장 안에 "그럴 만하다"를 준다.
설명부터 시작하지 않는다. **장면부터 씁니다.**

구인 사이트를 열어 두고 검색창에 뭘 넣어야 할지 몰라 한참 그대로 두는 장면.

## 글 구조 (h2 5개)

1. **막막한 게 당연합니다**
   준비가 부족해서가 아니라 **기준이 없어서** 막막한 것이라는 점을 짚는다.
   짧게 끝냅니다.

2. **먼저 정리할 것은 이력이 아니라 조건입니다**
   이 글의 중심. 이력서를 고치기 전에 시간·거리·강도 같은 **내가 지킬 조건**을
   먼저 적어 보는 순서를 이야기한다.
   (하루 몇 시간까지 / 오가는 시간은 얼마까지 / 서서 하는 일이 가능한지 / 주말 여부)

3. **해 온 일을 다시 세어 봅니다**
   경력을 직함이 아니라 **해낸 일**로 다시 적어 보는 방식.
   가정에서 해 온 일, 잠깐 했던 일, 봉사도 포함된다는 점을 짚는다.
   ⚠️ "무엇이든 경력이 된다" 같은 과장으로 가지 않는다.

4. **어디를 먼저 볼까요**
   공공 고용 서비스·지자체 센터·평생교육 같은 **경로의 종류**까지만 이야기한다.
   ⚠️ 기관명·사이트명·업체명·앱 이름을 **하나도 쓰지 않는다.**
   "가까운 곳에 상담 창구가 있다" 수준으로 둔다.

5. **혼자 알아보면 지칩니다**
   같은 고민을 지나온 사람들의 이야기가 실제로 도움이 된다는 점을 짚는다.
   여기서 자연스럽게 커뮤니티로 넘긴다.

