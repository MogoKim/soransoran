## 이 글에서 가장 조심할 것

**구체적인 숫자를 쓰는 순간 이 글은 위험 등급이 올라간다.**

```
🚫 감액률 퍼센트 ("1년 일찍 받으면 6% 줄어듭니다")
🚫 구체 금액 ("월 100만 원이 76만 원이 됩니다")
🚫 손익분기 나이 ("77세가 분기점입니다")
🚫 계산식
```

숫자가 틀리면 독자가 **실제로 손해를 본다.** 이 글은 **판단의 축**만 알려주고,
정확한 금액은 본인이 확인해야 한다는 데서 멈춘다.

## 검색 의도

```

```

독자는 **이미 조기수령이라는 제도가 있다는 건 안다.** 알고 싶은 것은 "나한테 유리한가"다.

50대 후반~60대 중반 여성.

- 퇴직했거나 곧 퇴직한다
- 소득 공백이 눈앞이라 당장 받고 싶은 마음이 있다
- 주변에서 "일찍 받으면 손해"라는 말을 들어서 헷갈린다
- 한 번 정하면 못 되돌린다는 게 부담이다

## 글 구조 (h2 5개)

1. **조기수령이 뭔가요**
   제도를 아주 짧게. 이미 아는 사람이 대부분이니 3~4문장이면 충분하다.

2. **일찍 받으면 무엇이 달라지나요**
   **구조만** 설명한다 — 매달 받는 금액은 줄고, 받는 기간은 길어진다.
   퍼센트를 쓰지 않는다.

3. **어느 쪽이 유리한지는 무엇으로 갈리나요**
   이 글의 핵심. 판단의 축을 3~4개 제시한다.
   (건강 상태와 예상 수명 / 지금 당장의 생활비 / 다른 소득이 있는지 / 배우자 연금)
   **정답을 주지 않는다.** 축만 준다.

4. **결정하기 전에 확인할 것**
   본인 기준 금액은 국민연금공단에서 확인하는 것이 정확하다는 점.
   링크는 걸지 않는다. 텍스트로만 언급한다.
   한 번 신청하면 되돌리기 어렵다는 점.

5. **혼자 정하기엔 무거운 결정입니다**
   숫자로만 정할 수 없는 결정이라는 것.
   비슷한 시기를 지난 사람들의 이야기가 도움이 된다는 방향으로 자유게시판에 연결.

## 반드시 그대로 넣을 문장 5개

**토씨 하나 바꾸지 마세요.** 창업자가 검수할 때 원문과 대조하는 문장입니다.

```
1. 일찍 받기 시작하면 매달 받는 금액이 줄어드는 대신 받는 기간이 길어집니다.
2. 어느 쪽이 유리한지는 건강 상태와 다른 소득이 있는지에 따라 갈립니다.
3. 구체적인 금액은 가입 기간과 소득에 따라 달라서 사람마다 다릅니다.
4. 실제 수령액은 국민연금공단에서 본인 기준으로 확인하는 것이 정확합니다.
5. 한 번 신청하면 되돌리기 어려운 결정이라 서두르지 않는 편이 좋습니다.
```

각 문장이 들어갈 자리: 1→h2 2 / 2→h2 3 / 3·4→h2 4 / 5→h2 4 끝 또는 인용
