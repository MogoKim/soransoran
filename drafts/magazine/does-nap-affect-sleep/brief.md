## 검색 의도

```
낮잠 밤잠 / 낮잠 자면 밤에 못 자나 / 오후에 졸림 / 낮잠 적당한 시간 / 낮잠 습관
```

**"낮에 졸린데 자도 되는지"** 를 알고 싶어 들어온다.
낮잠이 나쁘다는 말을 어디선가 들었는데, 정작 오후만 되면 눈이 감긴다.

## 대상 독자

50대~60대 여성. 오후에 졸음이 오는 사람이다.

- 점심 먹고 나면 눈꺼풀이 무거워진다
- 잠깐 눈을 붙였다가 한참 지나 깬 적이 있다
- 그런 날 밤에 잠이 잘 안 온 것 같기도 하다
- "낮잠 자면 안 된다"는 말을 들어서 참고 버틴다

## 도입에서 해야 할 것

첫 두세 문장 안에 "그럴 만하다"를 준다.
설명부터 시작하지 않는다. **장면부터 씁니다.**

점심 뒤 소파에 앉았다가 눈이 스르르 감기는 장면,
참아 보려다 결국 고개가 꺾이는 장면.

## 글 구조 (h2 5개)

1. **오후에 졸린 건 이상한 일이 아닙니다**
   하루 중 자연스럽게 졸음이 오는 때가 있다는 설명.
   단정하지 말고 "이야기됩니다" 수준으로. **짧게 끝냅니다.**

2. **낮잠이 밤잠을 방해할 때가 있습니다**
   방해가 되는 조건을 목록 4~5개.
   (너무 길게 잘 때 / 늦은 오후에 잘 때 / 깊이 잠들 때 /
    원래 밤에 잘 못 자는 편일 때)
   "전부 해당하는 건 아니다"를 반드시 붙인다.

3. **그렇다고 참는 게 답은 아닙니다**
   졸린 걸 억지로 버티면 오후 내내 집중이 안 되고 저녁에 더 지친다는 점.
   ⚠️ **낮잠을 금지하는 톤으로 가지 않는다.**

4. **자기 좋은 낮잠은 이런 모양입니다**
   길이보다 **결**을 이야기한다. 짧게, 이른 오후에, 눕기보다 기대어.
   ⚠️ 몇 분이라고 숫자로 처방하지 않는다.

5. **사람마다 다릅니다**
   낮잠이 잘 맞는 사람도 있고 아닌 사람도 있다는 점을 짚는다.
   여기서 자연스럽게 커뮤니티로 넘긴다.

## 반드시 그대로 넣을 문장 5개

**토씨 하나 바꾸지 마세요.** 창업자가 검수할 때 원문과 대조하는 문장입니다.
다듬거나 합치거나 순서를 바꾸면 검수 대조가 실패해 원고를 다시 받아야 합니다.

```
1. 오후에 졸음이 오는 것은 자연스러운 일이라고 이야기됩니다.
2. 낮잠이 밤잠에 어떤 영향을 주는지는 사람마다 다릅니다.
3. 낮잠을 잤다고 해서 밤에 잠이 안 오는 것은 아닙니다.
4. 졸린 것을 억지로 참는다고 밤잠이 좋아지지는 않습니다.
5. 밤에 잠들기 어려운 날이 오래간다면 병원에서 확인해 보시는 편이 좋습니다.
```

각 문장이 들어갈 자리: 1→h2 1 / 2→h2 2 / 3→h2 2 / 4→h2 3 / 5→h2 5

**1~2편과 같은 톤을 유지합니다.**

- 존댓말. 상담해 주는 톤이 아니라 **옆에서 같이 이야기하는** 톤
- 문단은 2~3문장. 길이를 일부러 들쭉날쭉하게
- 목록은 3곳을 넘기지 않는다. 나머지는 산문

- 소리 내어 읽었을 때 어색하면 고친다
