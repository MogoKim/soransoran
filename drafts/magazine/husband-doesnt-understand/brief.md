## 이 글의 자리

- 단발 글 (시리즈 아님)
- 클러스터: 가족
- 위험 등급: LOW — 마음과 관계를 다루는 글이다. 의학 설명을 하지 않는다

## 검색 의도

```
남편이 갱년기 이해 못함 / 갱년기 남편한테 말하기 / 갱년기 부부 갈등 / 남편이 몰라줘요
```

**"내가 예민한 건지"를 확인하러 들어온다.**
남편을 바꾸는 방법보다, 이해받지 못하는 서운함을 어떻게 두어야 할지를 알고 싶다.

## 대상 독자

40대 중반~50대 여성. 갱년기를 겪고 있고 배우자와 함께 사는 사람이다.

- 힘들다고 말하면 "다들 그런 거 아니냐"는 답이 돌아온다
- 설명하려다 말고 **그냥 삼킨다**
- 몸이 힘든 것보다 **혼자인 것 같은 기분**이 더 지친다
- 싸우고 싶지는 않아서 더 말을 아낀다

## 도입에서 해야 할 것

첫 두세 문장 안에 "그 서운함이 이상한 게 아니다"를 준다.
설명부터 시작하지 않는다. **장면부터 쓴다.**

저녁에 힘들다고 한마디 꺼냈다가, 돌아온 반응에 말문이 닫히는 장면.

## 글 구조 (h2 5개)

1. **왜 말이 잘 안 통할까요**
   겪어 보지 않은 변화는 설명해도 잘 전달되지 않는다는 점을 짚는다.
   **남편을 탓하는 구도로 쓰지 않는다.** 이해의 문제로 둔다.

2. **자주 어긋나는 순간**
   목록 5개 안팎.
   (힘들다고 말했을 때 / 갑자기 더워할 때 / 잠을 설쳤다고 할 때 /
    기분이 오르내릴 때 / 병원 이야기를 꺼낼 때)
   "집집마다 다르다"를 반드시 붙인다.

3. **설득하려 하지 않아도 됩니다**
   이 글의 핵심. 이해시키는 것이 목표가 되면 더 지친다는 관점을 준다.
   말하는 것 자체에 의미가 있다는 쪽으로 둔다.

4. **말을 꺼낼 때 조금 달라지는 것**
   부담 없는 것 4개 안팎.
   (감정보다 상황을 먼저 말하기 / 한 번에 하나만 / 지금 필요한 것을 짧게 말하기 /
    답을 바라지 않는다고 미리 말하기)
   대화법을 가르치는 톤이 되지 않게 한다.

5. **같은 이야기를 나눌 곳**
   집에서 못 한 이야기를 할 자리가 있으면 다르다는 감각을 준다.
   여기서 자연스럽게 커뮤니티로 넘긴다.

## 반드시 그대로 넣을 문장 5개

**토씨 하나 바꾸지 마세요.** 창업자가 검수할 때 원문과 대조하는 문장입니다.
다듬거나 합치거나 순서를 바꾸면 검수 대조가 실패해 원고를 다시 받아야 합니다.

```
1. 겪어 보지 않은 변화는 설명해도 잘 전해지지 않습니다.
2. 어느 순간에 어긋나는지는 집집마다 다릅니다.
3. 이해시키는 것이 목표가 되면 더 지치게 됩니다.
4. 말이 통하지 않는다고 해서 마음까지 없는 것은 아닐 수 있습니다.
5. 집에서 못 한 이야기를 할 곳이 있으면 조금 달라집니다.
```

각 문장이 들어갈 자리: 1→h2 1 / 2→h2 2 / 3→h2 3 / 4→h2 3 끝 또는 인용 / 5→h2 5

마음이 조금 가벼워지는 글이어야 한다.
