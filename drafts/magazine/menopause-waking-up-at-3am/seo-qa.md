## 주의로 남긴 것

### ① 시리즈 UI가 아직 없다 (항목 17) — 가장 중요

`seriesId: 'menopause-basic'` · `seriesOrder: 2` 를 지시대로 넣었다. 그런데 **실측 결과**:

```
getSeriesArticles / getAdjacentMagazineArticles   → src/ 사용처 0건
MagazineSeries 타입                                → 정의만 있고 레코드 없음
[slug]/page.tsx 가 import 하는 헬퍼                 → getRelatedMagazineArticles 뿐
```

6-G-1에서 **계산 헬퍼는 만들었지만 UI에 연결하지 않았다.**
따라서 이 글을 그대로 발행하면 "이전 글 / 다음 글 / 이 시리즈" 섹션이 **화면에 나오지 않는다.**
데이터는 맞게 들어가 있으므로 나중에 UI만 붙이면 소급 수정 없이 살아난다.

→ 판단이 필요하다: 6-E-5에 시리즈 UI를 포함할지, 글만 먼저 낼지. `publish-plan.md` §3.

### ② cluster를 `sleep` 이 아니라 `menopause-symptom` 으로 둔 이유 (항목 18)

전략서 §8 주제 큐의 day 2는 이 글을 **단발 · `sleep` 클러스터**로 잡고 있다. 지시는 "갱년기/증상 계열"이다.
`menopause-symptom` 을 택했다.

```
sleep 선택 시              → 현재 sleep 글이 0건이라 관련글도 0건. 두 글 사이 내부링크가 전혀 없다
menopause-symptom 선택 시  → 첫 글과 상호 관련글로 연결된다 (getRelatedMagazineArticles)
```

시리즈 UI가 없는 지금(①), 관련글이 **두 글을 잇는 유일한 내부링크**다.
`sleep-series` 5편을 시작할 때 이 글을 그쪽으로 옮길지는 그때 결정하면 된다(슬러그는 그대로 두므로 URL 변경 없음).

### ③ hero 이미지는 이번에 넣는 편이 낫다 (항목 19)

6-E-3에서 `og:image` 연결이 끝났다. hero 가 있으면 카카오톡·네이버 공유 시 큰 카드가 뜨고,
없으면 `og:image` 키 자체가 생략되어 텍스트 카드가 된다.
첫 글은 이미지를 넣었으므로, 두 번째 글만 텍스트 카드가 되면 목록·공유 인상이 어긋난다.

### ④ 전략서 주제 큐와의 차이 3건 (기록용)

| 항목 | 전략서 §8 day 2 | 이번 초안 | 사유 |
|---|---|---|---|
| slug | `menopause-wake-3am` | `menopause-waking-up-at-3am` | 지시된 디렉터리명 |
| type | 단발 | 시리즈 `menopause-basic` #2 | 지시 |
| cluster | `sleep` | `menopause-symptom` | 지시 + ② |

이 글이 `menopause-basic` #2가 되면 전략서상 #2였던 "갱년기 안면홍조 언제까지 계속되나요"(day 4)가 #3으로 밀린다.
주제 큐 코드화(6-G-2) 때 반영이 필요하다.

## 창업자가 사실관계를 확인해야 할 항목

```
□ "잠은 얕아졌다 깊어졌다를 반복하고, 얕은 구간에서 잠깐 깨는 일은 누구에게나 일어난다"
□ "이 시기 호르몬 변화가 몸의 여러 리듬에 영향을 준다고 이야기된다" — 단정이 아닌 서술로 충분한가
□ "술은 잠은 빨리 들지만 새벽에 더 자주 깨는 편이다"
□ "갑상선·빈혈·오래 쌓인 스트레스도 비슷한 느낌을 줄 수 있다"
□ 위험 신호 4종(숨 막힘·가슴 통증·심한 우울감·몇 주째 낮 생활 곤란)이 적절한 범위인가
```

⚠️ 사실관계는 **창업자 검수 필수**다(전략 원칙 5). 일반적으로 통용되는 선에서 썼고
약·호르몬 치료·영양제는 일절 언급하지 않았으나, **발행 책임은 창업자에게 있다.**

## 발행 전 눈으로 확인할 문장 5개

```
1. 도입 2문단
   "잠이 얕아진 것이 갱년기와 관련이 있을까 싶어 검색해 보면 무서운 이야기부터 나옵니다."
   → "나만 이런가"를 받아주는 톤인가, 아니면 검색 결과를 깎아내리는 것처럼 읽히는가

2. h2 1 callout
   "'새벽 3시'라는 시간 자체에 특별한 의미가 있는 것은 아닙니다."
   → 제목이 "새벽 3시"인데 본문에서 해제하는 구성이 어색하지 않은가

3. h2 2 도입
   "이 시기에는 호르몬 변화가 몸의 여러 리듬에 영향을 준다고 이야기됩니다."
   → 의료 단정으로 읽히지 않는가

4. h2 4 callout
   "숨이 막혀 깨거나 가슴이 아플 때 … 혼자 견디지 마시고 전문가와 상담해 보세요."
   → 겁주는 쪽으로 기울지 않는가 (분량·표현)

5. CTA
   "'나도 새벽에 자주 깬다', '요즘 잠 때문에 힘들다' — 짧아도 괜찮습니다."
   → 광고처럼 느껴지지 않는가. 첫 글 CTA와 문장 톤이 이어지는가
```
