## 이 글의 자리

- 단발 글 (시리즈 아님)
- 클러스터: 마음 — **이 클러스터의 첫 글이다.** 앞으로의 톤 기준이 된다
- 위험 등급: MEDIUM — 왜 그런지 설명하고 마음을 짚는 데까지. 진단·치료는 다루지 않는다
- 내부 링크: 갱년기 시작 시기를 다룬 글과 이어진다

## 검색 의도

```
갱년기 눈물 / 이유 없이 눈물이 나요 / 갱년기 감정기복 / 갑자기 울컥 / 갱년기 우울
```

**"내가 왜 이러는지"를 알고 싶어 들어온다.**
이상해진 게 아니라는 확인을 원하고, 병원에 가야 할 정도인지 가늠하고 싶다.

## 대상 독자

40대 중반~50대 여성. 감정이 예전 같지 않다고 느끼는 사람이다.

- 드라마나 광고를 보다가 **갑자기 울컥한다**
- 별일 아닌 말에 눈물이 나고 스스로 당황스럽다
- 가족 앞에서 그러고 나면 **민망해서 더 숨긴다**
- 예전에는 이러지 않았는데 싶어 **내가 이상해진 건가** 걱정된다

## 도입에서 해야 할 것

첫 두세 문장 안에 "이상해진 게 아니다"를 준다.
설명부터 시작하지 않는다. **장면부터 쓴다.**

혼자 있다가, 또는 아무렇지 않은 대화 중에 갑자기 눈시울이 뜨거워지는 그 장면.

## 글 구조 (h2 5개)

1. **왜 갑자기 눈물이 날까요**
   호르몬 변화가 감정 조절에 영향을 준다는 설명.
   단정하지 말고 "이야기됩니다" 수준으로. 기전을 자세히 설명하지 않는다.

2. **이럴 때 자주 그렇습니다**
   방아쇠가 되는 상황을 목록 5개 안팎.
   (잠이 부족할 때 / 혼자 있을 때 / 사소한 말을 들었을 때 /
    피곤이 쌓였을 때 / 몸이 힘든 날)
   "사람마다 다르다"를 반드시 붙인다.

3. **눈물이 난다고 이상한 게 아닙니다**
   이 글의 핵심. 감정이 오르내리는 것이 이 시기에 흔하다는 안심을 준다.
   **우울증으로 단정하지 않는다.** 다만 언제 진료를 생각해 볼지는 짚는다.

4. **오늘 해볼 수 있는 것**
   부담 없는 것 4개 안팎.
   (참지 않고 울어도 된다 / 잠을 조금 더 자기 / 짧게 걷기 /
    가까운 사람에게 미리 말해 두기)
   "이겨내세요" 같은 명령형을 쓰지 않는다.

5. **숨기지 않아도 되는 곳**
   가족 앞에서 감춘 마음을 꺼낼 자리가 있으면 다르다는 감각을 준다.
   여기서 자연스럽게 커뮤니티로 넘긴다.

## 반드시 그대로 넣을 문장 5개

**토씨 하나 바꾸지 마세요.** 창업자가 검수할 때 원문과 대조하는 문장입니다.
다듬거나 합치거나 순서를 바꾸면 검수 대조가 실패해 원고를 다시 받아야 합니다.

```
1. 호르몬 변화가 감정을 조절하는 방식에 영향을 준다고 이야기됩니다.
2. 어떤 순간에 눈물이 나는지는 사람마다 다릅니다.
3. 눈물이 잦아졌다고 해서 이상해진 것이 아닙니다.
4. 다만 가라앉는 기분이 몇 주 넘게 이어지거나 일상이 어렵다면 병원에서 확인해 보시는 편이 좋습니다.
5. 참으려 애쓰지 않아도 괜찮습니다.
```

각 문장이 들어갈 자리: 1→h2 1 / 2→h2 2 / 3→h2 3 / 4→h2 3 끝 또는 인용 / 5→h2 4
